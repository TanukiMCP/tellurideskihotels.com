## Step 2: Content Body Review & Polish

### Text Quality Standards

1. **Voice Check:** The article should read like a knowledgeable local friend—specific details, insider tips, no generic travel clichés ("hidden gem," "breathtaking," "off the beaten path").

2. **Paragraph Structure:** 2-4 sentences max per paragraph. Break up any walls of text. Mobile-friendly formatting.

3. **Bullet Point Usage:** Bullets should be RARE (3-5 item max for quick reference lists only). 90% of content should be narrative paragraphs, not outline format.

4. **Specificity:** Replace any vague descriptions with concrete details:
   - BAD: "Beautiful mountain views"
   - GOOD: "Views of 14,000-foot Wilson Peak from your balcony"

5. **Active Voice:** 80%+ of sentences should be active voice. Fix passive constructions.

6. **Subheadings:** Ensure an H2 every 300-400 words. All H2s should be descriptive and keyword-rich.

### Widget Selection Decision Tree

**Ask yourself for each section:**

1. **Is this a listicle where each hotel gets its own numbered entry?**
   → Use `<HotelShowcase hotelId="..." showGallery={true} />` after each hotel description

2. **Are 2-3 hotels mentioned together in a category discussion?**
   → Use `<HotelGrid hotelIds={["id1", "id2", "id3"]} title="..." />`

3. **Is this discussing costs, budgets, or group trip planning?**
   → Use appropriate planning tool: `GroupCostCalculator`, `BudgetToItineraryPlanner`, `HotelSplitCalculator`

4. **Is this comparing options (hotel vs condo, peak vs off-peak)?**
   → Use `SeasonComparison`, `HotelSplitCalculator`, or `LodgingComparisonMatrix`

5. **Is this a transition point or general CTA without specific hotels mentioned?**
   → Use `<ArticleBookingWidget variant="compact" filter="..." />`

6. **Is this the end of the article?**
   → Use `<ArticleBookingWidget variant="featured" />` (REQUIRED)

7. **Is this discussing activities, dining, or experiences?**
   → Use `<ActivityShowcase category="..." />` or link to `/things-to-do`

8. **Is this discussing geography, locations, or comparing downtown vs Mountain Village?**
   → Use `<BlogMap preset="overview" />` to visually show both areas

9. **Is this a ski terrain or trail discussion?**
   → Use `<BlogMap preset="trails" terrain={true} />` to show trail difficulty

10. **Does the article need visual variety (too many hotel widgets in a row)?**
   → Add a `<BlogMap />` between hotel sections to break up the page visually
